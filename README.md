# C Programming Exercises

A collection of exercises and practical work from my first year studying Computer Engineering at EMSI.

I created this repo to practice algorithms, get comfortable with standard C concepts, and track my learning progress over time.

## 📚 Topics Covered

* Fundamentals & Control Flow : Variables, data types, logic ( 'if' , 'switch' ) , and loops ( 'for' , 'while' , 'do-while' ) .
* Data Structures : Arrays (1D & 2D matrices) , string handling and manipulation .
* Core Concepts : Functions, pointers and dynamic memory allocation .
* Algorithms: Searching, sorting and general problem-solving techniques .

## 📁 Repository Structure

Inside , you'll find focused exercises targeting specific concepts as well as larger scripts combining multiple techniques studied throughout the year.

* **Language:** C

* **Editor:** Visual Studio Code
